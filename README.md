# 🌸 About ClassTeams

> *"Built for students who want control, not chaos."* 🎯

ClassTeams is a **modern academic dashboard** inspired by **Google Classroom**, designed to simplify academic management through a clean interface and scalable full-stack architecture.

Unlike a simple classroom UI clone, ClassTeams integrates a real backend using **Supabase**, allowing the application to evolve into a complete learning platform.

Whether you're managing assignments, schedules, course resources, or future collaborative features, ClassTeams provides a centralized workspace that helps students stay productive and organized.

# ⚙️ Environment Variables

Create a file named

```
.env.local
```

Then add

```env
NEXT_PUBLIC_SUPABASE_URL=your_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_project_key
```

You can obtain these credentials from your **Supabase Project Dashboard**.

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ClassTeams.git
```

Go to project

```bash
cd ClassTeams
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
